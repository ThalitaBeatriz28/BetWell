Bolão digital da Copa do Mundo 2026. Você envia o seu palpite de placar para cada partida, e o sistema compara com o resultado oficial na hora, mostrando se você cravou o placar, acertou o vencedor ou errou. Tudo acontece na própria página, com histórico de palpites. 📋

Feito com **HTML, CSS e JavaScript** puros, sem frameworks e sem instalação. 🚀

## 🚀 Como jogar

1. 🌐 Acesse o site https://thalitabeatriz28.github.io/BetWell/
2. ✍️ Digite o seu placar em cada campo
3. 📨 Clique em **ENVIAR** e veja o resultado no histórico

---

## ✨ O que você encontra

| 🏟️ Seção | 🎯 O que faz |
|---|---|
| 🔥 **Principais partidas** | Cards com as seleções, a data e o horário de cada jogo |
| ✍️ **Palpite** | Dois campos numéricos (0 a 10) para o placar de cada time |
| 📨 **Enviar** | Confere o palpite e registra o resultado no histórico |
| 📜 **Histórico** | Lista em ordem de envio, com a cor de cada resultado |

---

## 🏅 Como a pontuação funciona

Cada palpite recebe um dos três resultados abaixo:

| Resultado | Quando acontece | Cor no histórico |
|---|---|---|
| 🥇 **ACERTOU EM CHEIO!** | O placar palpitado é exatamente o placar oficial | 🟩 Verde |
| 🥈 **Acertou o vencedor** | Você acertou quem venceu, ou acertou o empate, mas não o placar exato | 🟨 Amarelo |
| 🥉 **Errou, treinar mais** | O vencedor previsto não é o real | 🟥 Vermelho |
